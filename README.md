# Heavenly Stories Bot

Telegram-бот **@HeavenlyStoriesBot** для христианских аудиосказок.

## Что уже умеет бот

- приветствие и удобное меню;
- одна бесплатная аудиосказка;
- закрытая библиотека для подписчиков;
- ежемесячная подписка через Telegram Stars;
- автоматическое сохранение оплаты и срока доступа;
- команды `/terms`, `/support`, `/paysupport` и `/status`;
- добавление аудиосказок администратором прямо из Telegram.

## Настройки

Секреты нельзя записывать в код или публиковать в GitHub. На сервере задайте:

| Переменная | Обязательно | Значение |
|---|---:|---|
| `TELEGRAM_BOT_TOKEN` | да | Токен из @BotFather |
| `ADMIN_USER_ID` | да | Числовой Telegram ID автора |
| `SUBSCRIPTION_STARS` | нет | Цена подписки в Stars, по умолчанию `250` |
| `SUPPORT_USERNAME` | нет | Username для поддержки |
| `DATABASE_PATH` | нет | Путь к SQLite, по умолчанию `/data/heavenly_stories.db` |

## Запуск

```bash
docker build -t heavenly-stories-bot .
docker run --rm \
  -e TELEGRAM_BOT_TOKEN='добавьте_на_сервере' \
  -e ADMIN_USER_ID='ваш_числовой_id' \
  -v heavenly-data:/data \
  heavenly-stories-bot
```

## Как добавить сказку

1. Отправьте аудио или голосовое сообщение боту.
2. Ответьте на него командой `/addstory free Название сказки` для бесплатной истории.
3. Для платной библиотеки используйте `/addstory premium Название сказки`.

Только пользователь с ID из `ADMIN_USER_ID` может добавлять материалы.

## Перед публикацией

1. Переключите репозиторий в режим **Private**.
2. Добавьте токен только в секретные переменные выбранного хостинга.
3. Укажите свой username поддержки.
4. Проверьте цену подписки в Stars и текст условий.
5. Сделайте тестовую оплату до публичного запуска.

Цифровые товары внутри Telegram должны оплачиваться через Telegram Stars (`XTR`).
